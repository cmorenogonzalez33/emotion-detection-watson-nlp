# emotion-detection-watson-nlp
AI-powered web application for real-time emotion detection using Watson NLP, Python, and Flask

# Emotion Detector System

Este proyecto consiste en una aplicación web basada en Inteligencia Artificial diseñada para detectar emociones en textos. Desarrollado como proyecto final, el sistema integra capacidades de Procesamiento de Lenguaje Natural (NLP) y se despliega mediante un microservicio robusto.

## Descripción del Proyecto
El "Detector de Emociones" utiliza la biblioteca **Watson NLP** para analizar cadenas de texto y clasificar las emociones subyacentes. El proyecto sigue un ciclo de vida de desarrollo de software completo, incluyendo:
- Desarrollo de lógica de detección en Python.
- Pruebas unitarias para asegurar la fiabilidad.
- Empaquetado de la aplicación.
- Implementación de una interfaz web con Flask.
- Análisis estático de código para garantizar la calidad.

## Estructura del Repositorio
- `emotion_detection.py`: Lógica central del detector.
- `server.py`: Servidor Flask para la interfaz web.
- `test_emotion_detection.py`: Suite de pruebas unitarias.
- `static/`: Recursos estáticos de la aplicación.
- `templates/`: Plantillas HTML para la interfaz.

## Tecnologías Utilizadas
- **Lenguaje:** Python 3.x
- **NLP:** Watson NLP Library
- **Framework Web:** Flask
- **Calidad de Código:** Pylint
